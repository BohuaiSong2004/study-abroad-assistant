Waypoint

Every application, every deadline, one plan.

Waypoint turns each program's rounds and requirements into a dated plan for you — documents, test scores, recommendation letters — and keeps it in sync when deadlines change.

  • Synced timelines. When a program moves a deadline, your plan moves with it.
  • Recommendation tracking. Invite recommenders by link; see who has submitted.
  • XML export. Download timelines and recommendation packets that validate against a published schema.
